# Multi Column Validation

The Multi column section is now available in the Wireframe Builder library in place of Card grid. Its inspector exposes the requested two-, three-, and four-column choices, the five content styles, style-specific media controls, Basic/Card presentation, and optional Read more links where applicable.

Live browser verification exercised Feature with icon media and card presentation; Blog with author, summary, and links; Service with no media and hidden optional links; Product collection with links; and Product with image, price, and a tertiary Add to cart action. The existing grayscale, square-corner website-section treatment remains intact for client handoffs.

## Restored Blog and Product styles

The editor now again presents Blog and Product in the Multi column Content style selector. Selecting Blog updates the section to `Latest insights` with image placeholders, post labels, author labels, summaries, and optional Read more links. Selecting Product updates the section to `Featured products` with image placeholders, product labels, price, and outlined Add to cart treatment; Product correctly omits the Read more control. Both treatments retain the existing desktop grid and mobile one-column handoff renderers.
