# Header Alignment Reference Notes

## LocalBusiness reference crops 1–2

The current LocalBusiness header uses a small cyan icon followed by an editorial title and compact uppercase toolbox label at the left edge. Its header row is separated from the workspace by a subtle horizontal rule. The middle of the row shows lightweight status labels, including a cyan-dot session indicator. The intended shared update will preserve the LocalBusiness identity while adopting Wireframe Builder’s more compact action-driven header structure.

## LocalBusiness reference crops 3–4

The current central status labels are divided by a subtle vertical separator. The only primary action is a cyan rounded **Save schema** button at the far right, with an outline-style copy action contained inside the generated JSON-LD card. The aligned header should keep saving as the primary right-side action, while removing the centered status strip in favor of the consistent flexible action area used by Wireframe Builder.

## Wireframe Builder reference crops 1–2

Wireframe Builder uses the same cyan icon, editorial title, compact uppercase toolbox label, and thin lower rule as the desired common pattern. Its identity remains grouped at the left, while contextual controls live in a right-aligned action area instead of a centered status strip. The LocalBusiness update will adopt this structural alignment while retaining a single Save schema action instead of device and export controls.

## Wireframe Builder reference crops 3–4

The right-side controls use consistent rounded-pill geometry, a cyan-filled primary action, and white outline secondary actions. The LocalBusiness header will use the same vertical centering, gap rhythm, header height, thin lower divider, and cyan primary-button geometry. The title remains unique to the LocalBusiness module, but the surrounding structure will read as the same Toolbox system.
