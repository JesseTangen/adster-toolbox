# Wireframe Builder Handoff Validation

The Wireframe Builder now uses a **left-side annotation rail** for desktop handoffs. Each rail places the section template name first and the strategist/design notes directly beneath it, next to the related website section. The mobile handoff keeps the same hierarchy by stacking the annotation rail immediately above each narrower section.

Both export controls were exercised in a live browser run. The desktop result is a JPEG at 2080 × 3136 pixels; the mobile result is a JPEG at 780 × 6764 pixels. The test also verified section add, title and note edits, duplication, drag reordering, and removal before downloading both files.
